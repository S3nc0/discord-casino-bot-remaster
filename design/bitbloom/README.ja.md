# Bitbloom

Bitbloom は、親しみやすいデザインシステムです。Material 3 の色の科学とコンポーネントの構造に、ピクセルアートの見た目を組み合わせています。居心地のよいゲーム、子ども向けや学習のアプリ、コミュニティのツールなど、楽しい雰囲気でありながら、誰にとっても使いやすくしたいものに向いています。

テーマはライトとダークの 2 つです。色の体系は、16 の色相を 11 のトーンずつ、そのトーンから作った M3 のカラーロール、そして 18 個のコンポーネントです。ピクセルらしさは、縁、影、アイコン、動きに表れます。文字は、とても読みやすい書体のままです。

## 原則

1. **まず読みやすさ、レトロはその次。** ピクセルフォントは大きな表示サイズだけに使います。人が読むものはすべて、Atkinson Hyperlegible の 16px 以上で組みます。
2. **大きくてわかりやすい操作領域。** タップできるものは、すべて 48×48px 以上です（`target-min`）。ラベルは、入力欄でもナビゲーションバーでも、常に見えるようにします。
3. **色だけに頼らない。** 選択中のチップにはチェックが付きます。バナーにはアイコンとタイトルが付きます。スイッチは On か Off と書きます。タグは色相と言葉を組にします。
4. **何が起きるかを伝える。** ボタンは動詞で始め、エラーは直し方を伝え、ダイアログは何が失われ、何が失われないかを伝えます。
5. **アートの 1 ピクセルは 2px。** 枠線、角の切り欠き、影、ステップは、すべて `pixel` の倍数です。ぼかしやアンチエイリアスはありません。

## 色

### パレット

16 の色相があり、それぞれにトーン 10、20、30、40、50、60、70、80、90、95、99 があります。色相は、red、orange、amber、yellow、lime、green、emerald、teal、cyan、sky、blue、indigo、violet、magenta、pink、brown です。これに加えて、`neutral` のパレット（0 から 100 までの 24 トーン）と、枠線や補足の文字に使う `neutral-variant` のパレット（ダークでは紺）があります。ライトのサーフェスは、温かみのある `paper` と `paper-variant` のパレットを使います。

トーンは M3 のルールに従います。数字は 0（黒）から 100（白）までの明度で、どの色相でも同じ意味を持ちます。そのため、コントラストの見当がつきます。

- トーンが **50 離れていれば**、少なくとも **4.5:1** になり、文字に安全です。例: `teal-90` の上の `teal-40`、`red-90` の上の `red-10`。
- トーンが **40 離れていれば**、少なくとも **3:1** になり、アイコン、枠線、大きな文字に十分です。

### ロール

生のトーンではなくロールで UI を組むと、どちらのテーマでも自動的にうまくいきます。すべてのロールは、パレットのトーンの別名です。

| ロール | ライト | ダーク | 用途 |
| --- | --- | --- | --- |
| `primary` | green-40 | green-70 | 主な操作、成功。新緑で、唯一の primary の色 |
| `secondary` | sky-40 | sky-70 | 情報、リンク、選択。トーナルボタン、チップ、ナビのインジケーター、スライダーのトラックは、`secondary-container` を使います |
| `tertiary` | yellow-40 | yellow-80 | ペリカ、報酬、ハイライト、コイン。控えめに使います |
| `error` / `success` / `warning` | red / green / orange 40 | red 70 / green 80 / orange 80 | 状態。警告は、黄色のアクセントと間違えないようにオレンジです |
| `surface` … `surface-container-highest` | paper 96 → 87 | neutral 10 → 24（紺） | 背景を重ねた層。ライトは温かい紙、ダークは深い紺 |
| `on-surface`、`on-surface-variant` | neutral-15、nv-35 | neutral-95、nv-80 | 文字。薄めません |
| `outline` | nv-50 | nv-65 | 意味を持つ枠線: 入力欄、ボタン、スイッチ、スライダー（3:1 以上） |
| `outline-variant` | paper-variant-80 | nv-30 | カード、リスト、ナビ、区切りに使う装飾用のトーンのある縁（約 1.5〜1.8:1）。コントロールの唯一の手がかりにはしません |
| `focus-ring` | indigo-40 | yellow-80 | キーボードのフォーカス。常に 3px |

`primary`、`secondary`、`tertiary`、`error`、`success`、`warning` には、M3 と同じく、それぞれ `on-*`、`*-container`、`on-*-container` が付きます。

### 色相のロール: UI の中のパレット

すべての色相には、テーマに合わせて変わるロールが 3 つあります。`<hue>-accent`（サーフェスの上のアイコンと文字）、`<hue>-container`（塗り）、`on-<hue>-container`（その塗りの上の文字）です。タグ、カテゴリー、レア度、グラフ、イラストに使います。16 色すべての色相が、両方のテーマで 4.5:1 を満たすので、コントラストを確かめずにどれでも使えます。

色相は意味で選び、一貫させます。ゲーム向けのおすすめの組は次のとおりです。

- **レア度:** common は neutral、uncommon は `green`、rare は `blue`、epic は `violet`、legendary は `yellow`。
- **属性:** 火は `orange`、水は `sky`、土は `brown`、自然は `lime`、氷は `cyan`、魔法は `magenta`。
- **グラフのカテゴリー:** 色相環の上で 3 段以上離れた色相を使い、トーンも変えて、色相だけでなく明るさも違うようにします。

## 書体

| ロール | フォントファミリー | サイズ |
| --- | --- | --- |
| Display、Headline、Title | Pixelify Sans（`font-display`） | 56 → 16px |
| Body、Label | Atkinson Hyperlegible（`font-body`） | 18 → 12px |
| 数字（お金、オッズ、順位、タイマー、個数） | Atkinson Hyperlegible の数字（`font-numeric`。`font-body` を指します） | すべて |

数字には Pixelify の字形を使いません。どの大きさでも 2 を 8 のように、5 を S のように描くためです。数字は `font-numeric`（アプリの `.num` ユーティリティ）で表示します。見出しの中では、アプリが数字だけの書体 `Bitbloom Numerals` を `font-display` の先頭に置くので、「Race 12」はピクセルの文字のまま、数字だけが読みやすくなります。`build_tokens.py` は `tokens.json` に `numeric` の書体を、`tokens.css` に `--font-numeric` を書き出します。

M3 の 15 スタイルのスケールをすべて使います。本文のサイズは、読みやすさのために、M3 より約 2px 大きくしてあります。`body-medium` は 16px で、人が読まなければならないものの下限です。`label-small`（12px）はバッジ専用です。ボタンも含めて、文は常に sentence case です。

## 形、奥行き、動き

- **ピクセルの枠線。** コントロールは、4 方向のハードな影のある 2px の枠線を描くので、四隅はちょうどアートの 1 ピクセルずつ欠けます（`step-sm`）。大きなサーフェスは、2 段の角（`step-lg`）を使ってかまいません。`border-radius` はどこにもありません。
- **奥行きはオフセットで、ぼかしではない。** `elevation-1` から `elevation-3` は、右下に 2、4、6px ずらした実線の影で、色は `neutral-variant-80`（ライト）か黒（ダーク）です。
- **押せるふち。** 塗りのボタンと FAB は、下側に 4px の濃いふち（`pixel-lip`）を持ち、押すとアートの 1 ピクセル分下に動きます。
- **ステートレイヤー。** M3 の不透明度をトークンとして保っています。`state-hover` 0.08、`state-focus` 0.10、`state-pressed` 0.12、`state-dragged` 0.16。
- **動きはコマ送り。** トランジションは、スプライトが動くときのように `steps(n)` のタイミングを使います。`prefers-reduced-motion` のときは、すべてオフになります。

## 余白

基本の単位は 4px で、`space-1`（4）から `space-12`（48）までです。`pixel`（2px）は枠線とアートに使います。カードの余白は、スマホでは `space-4`、大きな画面では `space-6` です。セクションの間は `space-8` あけます。

## アイコンとアート

ピクセルアートは、ナビのアイコンと同じように、行の文字列（アートの 1 ピクセルを 1 文字で表す）として、コードの中で描きます。キットには、16×16 のゲームアイコン 9 つ（サイコロ、スロット、トランプ、ルーレット、馬、株、つるはし、剣、コイン）、夜と昼のスカイラインの帯、スパークルが入っています。`packages/ui/src/pixel/` の `GameIcon`、`Skyline`、`Sparkle` です。各文字は、`.bb-px-*` か `.bb-sky-*` のクラスを通してパレットのトーンに対応するので、色はインラインに書かれず、スカイラインもテーマに従います。コインの上下とスパークルのきらめきは `steps(2)` で動き、どちらも動きを減らす設定では止まります。

- アイコンは 12×12 のグリッドに描き、24px（アートの 1 ピクセルが 2px）で表示し、`currentColor` で塗ります。線はアートの 1 ピクセル幅にし、1 ピクセルの余白を残します。
- イラストとアバターは 8、16、32px で描き、整数倍で拡大し、`image-rendering: pixelated` を指定します。
- アートはパレットのトーンで描き、どちらのテーマでも UI となじませます。グラデーションは使わず、混ぜたいときはディザリング（2 つのトーンの市松模様）を使います。

## アクセシビリティのチェックリスト

- 文字は 4.5:1 以上、枠線、アイコン、フォーカスリングは 3:1 以上。すべてのロールが、両方のテーマでこれを満たします。
- 操作領域は 48px 以上で、チェックボックス、ラジオ、スイッチは行全体がクリックできます。
- すべてのコントロールに、見えるフォーカスを付けます。`focus-ring` を 5px のオフセットで使います。
- ラベルは常に表示します。プレースホルダーは例であって、ラベルではありません。
- 状態を、色だけで示しません。
- 動きは、動きを減らす設定に従います。

## トークンの作成と確認

`python3 design/bitbloom/build_tokens.py` は、`proposal/archive/` に残してある元のパレットから、`tokens.json` と `tokens.css` を作り直します。`python3 design/bitbloom/contrast_check.py` は、両方のテーマですべてのロールの組を確認します（396 件のチェック。1 つでも失敗すると 1 で終了）。CI は、同じルールを `packages/ui/src/styles/contrast.test.ts` として、アプリが読み込む CSS に対して実行し、それが `tokens.json` と一致することも確認します。

## 使い方

`tokens.css` を読み込み、次に `components/bundle.css` を読み込みます。どのコンポーネントも、素の HTML 要素に付ける `bb-` で始まる普通の CSS クラスなので、JavaScript もフレームワークも入れる必要はありません。各コンポーネントのページに、マークアップと状態が載っています。
