# Banner

状況が変わるまでページに残る、インラインのメッセージです。トーンは 4 つあります。

- トーン: `--info`（空色）、`--success`、`--warning`、`--error`。それぞれ、コンテナと on-container のロールを使い、同じトーンのピクセルの枠線が付きます。
- どのバナーにもアイコンと太字のタイトルがあるので、トーンが色だけに頼ることはありません。
- エラーは `role="alert"`、それ以外は `role="status"` を使います。
- 何が起きたか、次に何をすればよいかを、やさしい言葉で書きます。タイトルにエラーコードは入れません。
