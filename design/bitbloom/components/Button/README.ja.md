# Button

M3 の 5 段階の強調度に対応する、ピクセルの縁のボタンです。人が意図して行う操作ならどれにでも使います。

| バリアント | クラス | 使う場面 |
| --- | --- | --- |
| Filled | `bb-btn` | 画面の主な操作。1 画面に 1 つだけ。 |
| Tonal | `bb-btn bb-btn--tonal` | 重要だが主ではない操作（友だちを招待する、下書きを保存する）。 |
| Outlined | `bb-btn bb-btn--outlined` | 塗りのボタンの横に置く、二次的な選択肢。 |
| Text | `bb-btn bb-btn--text` | 目立たせない操作: スキップ、詳しく見る、ダイアログのキャンセル。 |
| Danger | `bb-btn bb-btn--danger` | 取り返しのつかない操作。ふつうは確認ダイアログの中で使います。 |

## 構造

- 最小の高さは 48px（`target-min`）、左右の余白は `space-5`、文字は `label-large` です。
- コンテナの一番濃いトーンの 2px のピクセルの枠線（`step-sm` の切り欠き）と、下側の 4px の `pixel-lip` が付くので、押せるブロックに見えます。
- 先頭に 24px のアイコンを付けられます。ラベルとの間隔は `space-2` です。

## 状態

- ホバー、フォーカス、押下には、M3 のステートレイヤーを使います（`state-hover` 8%、`state-focus` 10%、`state-pressed` 12%）。
- 押すと、ボタンがアートの 1 ピクセル分下がります。キーボードのフォーカスでは、`focus-ring` のアウトラインが付きます。
- 無効のときは `disabled-container` と `on-disabled` を使います。理由がわかりにくいときは、ボタンの横に理由を書きます。隠さないでください。

## ラベルの書き方

動詞で始めて、何が起きるかを伝えます。「OK」ではなく「種をまく」のようにします。2、3 語で、sentence case にします。
