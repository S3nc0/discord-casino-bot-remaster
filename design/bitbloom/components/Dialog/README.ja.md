# Dialog

先に進む前に答えが必要な判断のための、モーダルです。M3 の basic dialog に、ピクセルの枠を付けたものです。

- `surface-container-high`、`outline` の枠線、`elevation-3`。背後に `scrim` を敷きます。
- 上に `secondary` の色のアイコンを置けます。タイトルは `headline-small` で、アイコンがあるときは中央に置きます。
- 本文には、何が起きるか、そして何が起きないかを、正確に書きます。
- 操作は右側に並べます。閉じる側は、テキストボタンで先に、確定する側は最後に置きます。確定のラベルは、タイトルの動詞を繰り返します（「OK」ではなく「削除する」）。
- Esc とスクリムのクリックでキャンセルします。フォーカスはダイアログの中に移り、閉じると戻ります。
