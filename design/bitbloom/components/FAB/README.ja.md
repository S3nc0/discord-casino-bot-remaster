# FAB

フローティングアクションボタンです。画面で一番よく使う操作を、`elevation-2` で浮かせて置きます。

- 既定の塗りは `primary-container` です。画面のアクセントに合わせたいときは、`--secondary` か `--tertiary` を使います。
- 高さは 56px です。ラベルの付いた extended 版のほうがわかりやすいので、はじめて使うときはそちらがおすすめです。
- 右下の角から 16px、ナビゲーションバーの上に置きます。1 画面に 1 つだけです。
- 押すと、右下に 1 ピクセル動き、影が `elevation-1` に下がります。
