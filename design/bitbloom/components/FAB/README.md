# FAB

The floating action button: the single most common action on a screen, raised at `elevation-2`.

- Default fill `primary-container`. Use `--secondary` or `--tertiary` when the screen's accent calls for it.
- 56px tall. The extended version adds a label and is easier to understand, so prefer it on first use.
- Place it 16px from the bottom-right corner, above the navigation bar. One per screen.
- Pressed moves it down-right by one pixel and lowers the shadow to `elevation-1`.
