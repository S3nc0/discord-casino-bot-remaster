# IconButton

A 48px square button with one pixel icon, for compact or repeated actions such as search, favorite or close.

- Variants: standard (`bb-icon-btn`), `--filled`, `--tonal`, `--outlined`, as in M3.
- Toggles set `aria-pressed`. Pressed turns the icon `primary`.
- Always give it an `aria-label`, and a tooltip when the icon isn't universal.
- Icons are 12×12 pixel art drawn at 24px, filled with `currentColor`.
