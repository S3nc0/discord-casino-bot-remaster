# List

関連する項目を並べた行です。先頭のピクセルのアバター、2 行のテキスト、右端のメタ情報を持ちます。Avatar も含みます。

- 行の高さは 72px、余白は `space-4` です。見出しは `body-medium` の太字、補足は `on-surface-variant` の `body-small` です。
- 選択中の行は `secondary-container` を使います。ホバーにはステートレイヤーを使います。
- Avatar: `outline-variant` の枠線を持つ、40px のピクセルアートの正方形。8×8 か 16×16 で描き、整数倍で拡大します。
- 行が 7 つほどを超えるときは、リストの上に検索か絞り込みのチップを置きます。
