# List

Rows of related items with a leading pixel avatar, two lines of text and trailing metadata. It includes the Avatar.

- Rows are 72px tall with `space-4` padding. Headline `body-medium` bold, supporting text `body-small` in `on-surface-variant`.
- Selected rows use `secondary-container`. Hover uses the state layer.
- Avatar: a 40px pixel-art square with an `outline-variant` border. Draw at 8×8 or 16×16 and scale by whole numbers.
- More than about 7 rows: add search or filter chips above the list.
