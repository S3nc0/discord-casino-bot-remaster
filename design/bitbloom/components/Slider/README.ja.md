# Slider

目盛りの上で値を選ぶためのレンジコントロールです。現在の値は、常にテキストでも表示します。

- `bb-slider` が、見出しの行（ラベルと値）と、ネイティブの range 入力を包みます。
- input の `--val` に、塗りつぶす割合を設定します。コードの中で、`input` イベントのたびに更新してください。
- トラックは、ピクセルの枠線のある 12px で、`primary` の塗りと、`secondary-container` の残りの部分でできています。つまみは、12×36 の `primary` の棒で、サーフェス色の隙間とアウトラインが付きます。
- そのほうがわかりやすいときは、数字の代わりに言葉で示します（「大」）。
