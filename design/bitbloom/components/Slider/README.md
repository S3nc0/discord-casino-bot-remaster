# Slider

A range control for picking a value along a scale, with its current value always shown as text.

- `bb-slider` wraps a head row (label and value) and a native range input.
- Set `--val` on the input to the filled percentage. Update it on `input` in your code.
- The track is 12px with a pixel border: `primary` fill, `secondary-container` remainder. The thumb is a 12×36 `primary` bar with a surface gap and an outline.
- Show words instead of numbers when that's clearer ("Large").
