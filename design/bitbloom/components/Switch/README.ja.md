# Switch

すぐに効く設定のための、オンとオフのコントロールです。

- `bb-switch` のラベルの中に、`role="switch"` を付けたネイティブのチェックボックスを置きます。
- トラックは 52×32 で、四角いピクセルのつまみは、オンになると 16px から 24px に大きくなります。動きは 3 コマ（`steps(3)`）で、スプライトのような感触です。動きを減らす設定では、まったく動きません。
- 色と位置だけでなく、スイッチの横に言葉（「On」/「Off」）でも状態を示します。
- 無効のときは、ラベルに理由を書きます。
