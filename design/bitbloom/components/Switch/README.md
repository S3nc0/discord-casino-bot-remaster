# Switch

An on/off control for settings that apply immediately.

- Native checkbox with `role="switch"` in a `bb-switch` label.
- Track 52×32, a square pixel thumb that grows from 16 to 24px when on. It moves in 3 steps (`steps(3)`) for a sprite-like feel, and doesn't move at all with reduced motion.
- Show the state as a word ("On" / "Off") beside the switch, not just with color and position.
- When disabled, put the reason in the label.
