# Tabs

M3 primary tabs, for switching between views of the same content.

- Each tab is 48px or taller, with an icon above the label (`label-large` at 14px). The selected tab is `primary` with a 6px stepped indicator bar.
- 2–5 tabs. Labels are one or two words. Don't use tabs for steps in a sequence.
- Arrow keys move between tabs and Enter selects (roving `tabindex` in your code).
