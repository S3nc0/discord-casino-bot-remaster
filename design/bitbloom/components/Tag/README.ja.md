# Tag

カテゴリー、レア度、状態を示す、16 色の色相のどれかで色づけした、動かないラベルです。UI の中で、大きなパレットが活躍する場所です。

- クラス: `bb-tag bb-tag--<hue>`（例: `bb-tag--violet`）。ロールの 3 つ組、`<hue>-container`、`on-<hue>-container`、`<hue>-accent`（枠線）を使うので、どの色相も両方のテーマで 4.5:1 を満たします。
- タグは操作できません。タップできるようにしたいときは、Chip を使います。
- 色は、言葉かアイコンと組にします。「Rare」の言葉と紫のタグを一緒に出し、紫だけにはしません。
- 色相は意味で選び、プロダクト全体で一貫させます。黄色が legendary を意味するなら、どこでも legendary を意味します。
