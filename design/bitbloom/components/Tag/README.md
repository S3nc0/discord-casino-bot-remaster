# Tag

A static label tinted from any of the 16 hues, for categories, rarities and statuses. This is where the large palette shows up in the UI.

- Class: `bb-tag bb-tag--<hue>`, for example `bb-tag--violet`. It uses the role trio `<hue>-container`, `on-<hue>-container` and `<hue>-accent` (border), so every hue passes 4.5:1 in both themes.
- Tags aren't interactive. Use Chip when people can tap them.
- Pair color with a word or icon: "Rare" plus a violet tag, never violet alone.
- Pick hues by meaning, and keep them consistent across the product: if yellow means legendary, it means legendary everywhere.
