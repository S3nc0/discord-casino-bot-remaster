# TextField

1 行のテキスト入力です。ラベルは常に、入力欄の上に表示します。M3 の outlined field を、もっと親しみやすくしたものです。

- ラベルはボックスの上にあり、浮き上がることも消えることもありません。プレースホルダーは例を示すだけで、ラベルの代わりにはなりません。
- ボックス: 高さ 48px、`surface-container-lowest` の塗り、`outline` のピクセルの枠線。フォーカスすると、枠線が `primary` に変わり、`focus-ring` が付きます。
- 補足のテキストは、下に `body-small` で書きます。エラーのときは `error` の色になり、警告のアイコンから始まって、直し方を伝えます。
- 先頭のアイコンは任意で、装飾です。
