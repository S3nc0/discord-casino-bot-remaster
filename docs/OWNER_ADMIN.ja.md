# オーナー向け管理コマンド・ID ガイド

[English](OWNER_ADMIN.md) | **日本語**

Discord の各種 ID とは何か、PC・スマホでのコピー方法、自分を Bot の管理者に登録する手順、そして `/admin`（`/運営`）の全コマンドの使い方をまとめたガイドです。

> [!CAUTION]
> **機密情報は絶対に公開しないでください。** **Bot Token**（`DISCORD_TOKEN`）、**OAuth2 Client Secret**（`DISCORD_CLIENT_SECRET`）、**`SESSION_SECRET`**、`.env` ファイルは絶対に他人に見せないでください。Discord の各種 ID 自体はパスワードのような機密ではありませんが、以下の例ではすべて架空の番号（`111111111111111111` など）を使っています。

---

## 1. サーバー ID とユーザー ID とは

Discord では、すべてのサーバー・ユーザー・チャンネルに、それぞれ固有の 17〜19 桁の数字である **ID** が割り振られています（Discord の設定や内部仕様では、サーバーのことを **guild（ギルド）**、この数字を *snowflake（スノーフレーク）* と呼びます）。

- **サーバー（guild）ID:** 特定の Discord サーバーを識別する番号です。サーバー名を変更しても ID は変わりません。
- **ユーザー ID:** 特定の Discord アカウントを識別する番号です。表示名やユーザー名を変えても ID は同じままです。
- **チャンネル ID:** サーバー内の特定のテキストチャンネル／ボイスチャンネルを識別する番号です。

`.env` や `/運営` コマンドでは、名前が変わっても間違った相手やサーバーを操作しないよう、この数字の ID を使います。

---

## 2. 開発者モードをオンにして ID をコピーする方法

初期状態では ID をコピーするメニューが隠れています。使っている端末ごとに一度だけ **開発者モード（Developer Mode）** をオンにすると、いつでも ID をコピーできます。

### PC（macOS / Windows / Linux）の場合

1. Discord を開き、左下の歯車アイコン（**ユーザー設定** / **User Settings**）をクリックします。
2. 左メニューの **詳細設定**（**Advanced**）を開き、**開発者モード**（**Developer Mode**）をオンにします。
3. 必要な ID をコピーします。
   - **サーバー ID:** 左端のサーバーアイコンを右クリック → **サーバー ID をコピー**（**Copy Server ID**）。
   - **ユーザー ID:** メンバーの名前やアイコン（自分自身も可）を右クリック → **ユーザー ID をコピー**（**Copy User ID**）。
   - **チャンネル ID:** テキストチャンネル名を右クリック → **チャンネル ID をコピー**（**Copy Channel ID**）。

### スマホ（iOS / Android）の場合

1. Discord アプリを開き、右下の **マイページ**（**You**／自分のアイコン）をタップします。
2. 右上の歯車アイコン（**設定**）→ **詳細設定**（**Advanced**）を開き、**開発者モード**（**Developer Mode**）をオンにします。
3. 必要な ID をコピーします。
   - **サーバー ID:** 左側のサーバーアイコンを長押し（またはサーバーを開いて上部のサーバー名をタップ → **`...`**）→ **サーバー ID をコピー**。
   - **ユーザー ID:** 相手の名前やアイコンをタップしてプロフィールを開く → 右上の **`...`** → **ユーザー ID をコピー**。自分自身の ID をコピーする場合は、右下の **マイページ** → 右上の **`...`** → **ユーザー ID をコピー**。
   - **チャンネル ID:** テキストチャンネル名を長押し → **チャンネル ID をコピー**。

## 3. 管理者（Bot オーナー）になる方法（`OWNER_IDS`）

Bot の管理者（オーナー）は、サーバーを動かしている Mac（または Raspberry Pi）上の `.env` ファイルにある `OWNER_IDS` で指定します。

1. プロジェクトフォルダ内の `.env` を開きます（まだ作っていない場合は [オーナー向けセットアップガイド — 手順 5](OWNER_SETUP.ja.md#5-mac-上に-env-を作成する) を参照してください）。
2. `OWNER_IDS` に自分の Discord ユーザー ID を設定します。

   ```sh
   OWNER_IDS=222222222222222222
   ```

   複数人を管理者にしたい場合は、ユーザー ID を **カンマ区切り**（スペースや引用符なし）で並べます。

   ```sh
   OWNER_IDS=222222222222222222,333333333333333333
   ```

3. `.env` を保存し、**サーバーを再起動** します（ターミナル 1 で `Ctrl+C` を押し、もう一度 `pnpm dev:server` を実行）。`.env` は起動時にしか読み込まれません。

> [!NOTE]
> スラッシュコマンドがまだ登録されていない場合は、一度 `pnpm commands:deploy:guild` を実行してください（[オーナー向けセットアップガイド — 手順 8](OWNER_SETUP.ja.md#8-チャットボットをオンにする)）。`OWNER_IDS` を編集しただけでコマンドを再登録する必要はありません。

## 4. `/運営`（`/admin`）を使える人と実行する場所

- **Bot オーナー（`OWNER_IDS`）:** **27 種類すべての `/運営`（`/admin`）コマンド** を使えます。
- **サーバー管理者（「サーバー管理」権限を持つメンバー）:** そのサーバー内でのみ **`/運営 通知設定`（`/admin notifications`）** を使えます。残りの 26 個の管理コマンドや、他サーバーの設定変更はできません。

### DM とサーバーチャンネルの違い

- **27 個のうち 26 個のコマンドは、Bot とのダイレクトメッセージ（DM）専用です。** サーバーのテキストチャンネルで `/運営` と打っても `/運営 通知設定` しか候補に出ません。残りのコマンドを使うときは、サーバーのメンバー一覧などから Bot をクリックして **DM を開き**、そこで `/運営` と入力してください。
- **`/運営 通知設定`（`/admin notifications`）** だけは例外で、**サーバー内と Bot との DM のどちらでも実行できます**。サーバー内で実行した場合、`サーバー`（`guild_id`）を省略するとそのサーバーが対象になります。

### DM でオプションを入力するときのコツ

- **`サーバー`（`guild_id`）:** ほとんどのコマンドでは入力欄をクリック・入力すると、Bot が知っているサーバーの候補一覧が出ます。`サーバー許可`・`サーバー取消` では数字のサーバー ID をそのまま貼り付けてください。
- **`ユーザー`（`user_id`）:** 先に `サーバー` を選ぶと、そのサーバーでアカウントを持つメンバーが候補に出ます（ユーザー ID や `@メンション` の直接入力も可）。対象のユーザーがそのサーバーで一度も Activity を開いておらずコマンドも使っていない場合は、対象外（未登録）になります。
- **`チャンネル`（`channel_id`）:** 開発者モードでコピーした数字のチャンネル ID を貼り付けます。`チャンネル` を指定するときは、あわせて `サーバー` も指定してください。
- **確認ボタンと入力フォーム:** `/運営` コマンドの返信はすべて自分だけに表示されます（エフェメラル）。残高の上書き・お知らせ送信・発言削除・抽選中止・クイズ削除・サーバー取り消しなどは、実行前にプレビューと確認ボタン（または入力モーダル）が出ます。

## 6. 管理者としての最初の 5 分間（手順ガイド）

はじめる前に、`.env` の `OWNER_IDS` に自分のユーザー ID が入っていて、サーバーを再起動済み、かつ `pnpm commands:deploy:guild` を実行済みであることを確認してください。

1. **テストサーバーで自分のプレイヤーアカウントを作成する:**
   テストサーバーのテキストチャンネルで `/ペリカ 残高`（`/pelica balance`）を実行する（または Activity を一度開く）と、そのサーバーにあなたのアカウントが登録されます。

2. **告知チャンネルを設定する:**
   テストサーバーのテキストチャンネルで次を実行します。
   - **日本語:** `/運営 通知設定 チャンネル:#your-channel 大当たり基準:1000 告知有効:True`
   - **英語:** `/admin notifications channel:#your-channel threshold:1000 enabled:true`

   自分だけに見えるメッセージで、新しい告知チャンネルが返ってきます。

3. **Bot との DM を開き、自分に 10,000 ペリカを付与する:**
   サーバーのメンバー一覧から Bot をクリック → **メッセージ** で DM を開き、自分のサーバー ID とユーザー ID を使って実行します。
   - **日本語:** `/運営 付与 サーバー:111111111111111111 ユーザー:222222222222222222 金額:10000 理由:管理コマンド動作確認`
   - **英語:** `/admin grant guild_id:111111111111111111 user_id:222222222222222222 amount:10000 reason:Admin smoke test`

   テストサーバーに戻って `/ペリカ 残高` を実行し、残高が **10,000 ペリカ** 増えていることを確認します。

4. **特別競馬レースを開催する:**
   Bot との DM で次を実行します。
   - **日本語:** `/運営 競馬開催 サーバー:111111111111111111 申し込み分:2 発売分:2`
   - **英語:** `/admin host-race guild_id:111111111111111111 entry_min:2 bet_min:2`

   テストサーバーの告知チャンネルに、レース告知と Activity を開くボタンが投稿されます。

5. **カジノのボーナスイベントを開始する:**
   Bot との DM で次を実行します。
   - **日本語:** `/運営 イベント 開始 ゲーム:スロット 時間:15 上乗せ率:50 サーバー:111111111111111111`
   - **英語:** `/admin event start game:Slots minutes:15 boost:50 guild_id:111111111111111111`

   告知チャンネルに **スロット +50%** のイベント告知が投稿されます。テストが終わったら `/運営 イベント 終了`（`/admin event stop`）でいつでも終了できます。
