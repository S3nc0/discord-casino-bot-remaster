# 用語集（英語 / 日本語）

旧ボット、YAML カタログ、挙動仕様、`packages/shared` で共通して使う、英語と日本語の正式な用語です。1 行に 1 語です。

## 経済とアカウントの基本

- **Pelica / ペリカ**：ボット内の仮想通貨です（整数、下限 `0`、記号 `P`）。
- **Initial Grant / 初期残高**：アカウント（`(guild_id, user_id)` ごと）に 1 回だけ付与する、開始時の残高 `3,000` ペリカです。
- **Per-Guild Economy / サーバー別経済**：残高、債務、持ち物、馬、会社、市場を `guild_id` ごとに完全に分けることです。
- **Ledger / 取引履歴**：`delta`、`balance_after`、`reason`、時刻を記録する、追記専用の残高変動ログです。
- **Escrow / エスクロー**：ゲームの決着前に預かる賭け金です。中止なら返金し、完了したら精算します。
- **Net Assets / 純資産**：下の貸借対照表の、総資産 − 負債です。ランキングの既定の並び順です（以前は、ここで誤って `総資産` としていました）。
- **Daily Bonus / デイリー**：JST の 6 時間ごとにリセットされる（1 日 4 枠）受け取り報酬で、連続受け取りに応じて増えます。
- **Streak Guard / ストリーク保護**：枠を逃したときに、デイリーの連続記録を守る消耗品です。
- **Daily Double / デイリー2倍**：次のデイリーの支払額を 2 倍にする消耗品です。
- **Transfer / 送金**：プレイヤー間のペリカの送金です。手数料の上限は `10%`、1 日の元本の上限は `20,000`、条件は `3` ゲーム以上です。
- **Weekly Champion / 週間王者**：週間の資格者のうち 1 位のプレイヤーに与える称号と報酬です（`min_plays = 5`）。
- **Mission / デイリーミッション**：シードから決まる毎日のプレイ目標で、達成するとペリカがもらえます。

## 資産（貸借対照表）

`/ペリカ ランキング`（表示 `純資産`・`流動資産`）・`/ペリカ 残高`・自動更新の掲示・内訳は、資産を貸借対照表（B/S）の区分で数えます。項目と区分は `packages/domain/src/progression/economy-core.ts` の `LIQUID_KEYS`・`FIXED_KEYS`・`LIABILITY_KEYS`、表示名は `packages/shared/i18n` の `bs.*` のキーです。ルールと数値は [economy-core.ja.md §3](economy-core.ja.md#3-貸借対照表純資産流動資産総資産)。

- **Current Assets / 流動資産**：すぐペリカにできる資産です。現金・預金（帝愛信託）・株式（現物の時価＋信用取引の評価額）・債券（元本）・オプション（評価額）・未収金（受け取る前の地下作業の稼ぎ）・預け金（競りへの入札）・貸付金（個人への貸付）。ランキングの 2 つ目の表示です。
- **Fixed Assets / 固定資産**：持っていて、すぐにはペリカにしない資産です。持ち物（買値）・発掘品（目安の価値）・競走馬（購入価格＋引退金の見込み）・会社（会社資金＋事業所の建設費）・地下作業の工具・寮（これまでの強化費用）。
- **Total Assets / 総資産**：流動資産 ＋ 固定資産（負債を引く前）です。
- **Liabilities / 負債**：借入金です。帝愛への借金（溜まった利息を含む）と、個人からの借入。
- **Net Assets / 純資産**：総資産 − 負債です。純資産のランキング（既定）・掲示・残高カードの順位に使います。「流動資産 ＋ 固定資産 − 負債 ＝ 純資産」は常に一致します。
- **Financial Net Worth / 金融純資産**：現金 − 帝愛への借金 ＋ 預金・株式・債券・オプションの評価額です。🟡 富豪の表示だけに使います（固定資産と個人間の貸し借りは含みません）。
- **Final Total Assets / ファイナル総資産**：廃止した以前の用語です。いまの純資産にあたります。

## プレイヤーの状態とランク

- **Katagi / カタギ**：債務のない標準的なプレイヤーの状態です。
- **Underground Laborer / 地下労働者**：帝愛銀行の債務（`debt > 0`）を抱えている間の状態です。
- **Bankruptcy Grace / 破産猶予**：帝愛の債務が `15,000` ペリカに達したときに始まる警告期間で、強制破産の前にあります。
- **Bankrupt / 破産者**：自己破産または強制破産のあとの状態です。資産の差し押さえ、債務の圧縮、融資のブラックリスト入りが起きます。
- **Wealthy / 富豪**：カタギで、金融純資産が `1,000,000` 以上の人につく表示です（表示だけです）。

## カジノゲーム

- **Chinchiro / チンチロ**：親と戦う 3 つ振りの日本のサイコロ賭博です。1 ターンに最大 3 回振れます。
- **Pinzoro / ピンゾロ**：`(1, 1, 1)` のゾロ目で、チンチロで最も強い役です（配当 `5` 倍）。
- **Arashi / アラシ**：`(2,2,2)`〜`(6,6,6)` のゾロ目で、チンチロで 2 番目に強い役です（配当 `3` 倍）。
- **Shigoro / シゴロ**：`(4, 5, 6)` の順子で、自動的にチンチロの勝ちになります（配当 `2` 倍）。
- **Me / 目**：2 つが揃い、残りの 1 つ（ポイントのサイコロ）が `(a, a, p)` の形です。`p`（`1`〜`6`）が点になります（配当 `1` 倍）。
- **Menashi / 目なし**：3 回振っても何も揃わない状態です。点のある手には必ず負けます。
- **Hifumi / ヒフミ**：`(1, 2, 3)` の順子で、自動的にチンチロの負けになります（`-2` 倍のペナルティ）。
- **Table pot / 総取り**：チンチロの卓（`/カジノ チンチロ卓`、2〜6 人）。全員が振り、いちばん強い役の人が、負けた人の賭け金から場代 `10%` を引いた分を受け取ります。並んだら山分け、全員が同じ強さなら全額返します。卓ではヒフミの倍払いはありません。
- **Pachinko / パチンコ**：予兆とティアによる当選確率、ラウンド倍率、配当セットを持つ、複数スピンのセット台です。
- **Omen / 予兆**：スピンの前に出る見た目のティアの目印で、パチンコの当選確率と対応します。
- **Slots / スロット**：重み付きの図柄抽選と、固定のラインの倍率を持つ 3 リールのスロットです。
- **Blackjack / ブラックジャック**：ディーラーと戦う標準的な 21 のカードゲームで、ヒット、スタンド、ダブルダウンができます。
- **Roulette / ルーレット**：ゼロが 1 つのヨーロピアン式（`0`〜`36`）のホイールです。赤／黒、偶数／奇数、前半／後半、ダズン、数字の指定の賭けができます。
- **Jackpot / ジャックポット**：外れた賭け金の一部を積み立てる、サーバー共有のプールです。条件を満たす賭けのとき、ランダムに当たります。
- **RTP Level / 設定**：サーバーごと、ゲームごとの払い戻しの調整レベル（`1`〜`6`）で、基本の理論 RTP を中心に純粋な勝ち分を増減させます。
- **Bonus Event / ボーナスイベント**：予定された、または管理者が起こす時間帯で、ゲームの純粋な勝ち分を増やします（既定は `+50%`）。

## 競馬と闘技場

- **Horse Racing / 競馬**：予定されたレース（JST で 1 日 4 回）と、特別な 8 頭立てのレースです。プレイヤーの馬と NPC の馬が走ります。
- **Horse Voucher / 馬券引換券**：新しいプレイヤーの馬を登録するときに使うショップの商品です（`30,000` ペリカ）。
- **Carrot / にんじん**：`speed`、`stamina`、`power`、`guts` の間でポイントを移す、能力の振り直しアイテムです。
- **Golden Carrot / 黄金のにんじん**：選んだ 2 つの馬の能力に、ポイントを恒久的に足す能力アップのアイテムです。
- **Running Style / 脚質**：ペースの型（`逃げ`、`先行`、`差し`、`追込`）で、レース中盤と終盤の速度の曲線を決めます。
- **Win / 単勝**：1 着の馬への賭けです。
- **Place / 複勝**：3 着以内に入る馬への賭けです。
- **Quinella / 馬連**：1 着と 2 着の 2 頭を、順不同で当てる賭けです。
- **Exacta / 馬単**：1 着と 2 着を、順番どおりに当てる賭けです。
- **Wide / ワイド**：3 着以内に入る 2 頭を、順不同で当てる賭けです。
- **Trio / 三連複**：1〜3 着の 3 頭を、順不同で当てる賭けです。
- **Trifecta / 三連単**：1 着、2 着、3 着を、順番どおりに当てる賭けです。
- **Retirement / 引退**：馬を恒久的に引退させ、戦績に応じたペリカの報酬を受け取ることです。
- **Arena / 闘技場**：毎日の NPC トーナメント（`duel` と `royale`）です。観客の賭け、武器ボーナス、補填されるプールがあります。

## 地下労働、発掘品、ミニゲーム

- **Underground Labor / 地下労働**：クリッカーと放置ワーカーによる採掘の経済です。つるはし、手袋、寮の強化、疲労、地形ボーナスがあります。
- **Fatigue / 疲労**：手動でクリックすると溜まる資源で、クリックの報酬を下げます。時間の経過かエナジードリンクで回復します。
- **Apprentice / 見習い**：入門レベルの放置労働ワーカーです。
- **Miner / 坑夫**：中位の放置労働ワーカーです。
- **Craftsman / 熟練工**：産出量の多い放置労働ワーカーです。
- **Foreman / 現場監督**：鉱石と発掘品のドロップ抽選に、運のボーナスを与える放置ワーカーです。
- **Relic / 発掘品**：常時バフを与える、まれな発掘ドロップです（`relic_fossil`、`relic_bone`、`relic_meteor`、`relic_vase`、`relic_crown`、`relic_tear`）。
- **Relic Merge / 合成**：同じ発掘品を `10` 個合わせて、次の星の段階（`★1`〜`★5`）に上げ、バフを強めることです。
- **Quiz / クイズ**：ユーザーが作る選択式のクイズで、正解率と参加者数に応じて、解いた人と作者に報酬が出ます。
- **Lottery / 抽選会（Raffle）**：サーバーのチケットプールで、参加者全員が定額で買い入れ、ランダムに選ばれた当選者 1 人が賞金を総取りします。
- **Poll / 投票**：期限つきのはい／いいえのサーバー投票です。有料の隠し票操作（1 回の調整につき `500` ペリカを帝愛銀行へ）があります。

## ショップとプレイヤーマーケット

- **Shop / ショップ**：称号、消耗品、引換券、スキン、時間で補充される商品の公式カタログです。
- **Teiai Seized Auction / 帝愛押収オークション**：破産したプレイヤーから押収したアイテムと馬の、割引再販です。時間とともに値下がりします。
- **Teiai Black Market / 帝愛闇市**：毎日ランダムに入れ替わる、割引商品とミステリーボックス（`reveal`）のカタログです。
- **Player Market / プレイヤーマーケット（P2P Market）**：プレイヤー間の固定価格と期限つきオークションの市場です。手数料は `5%` で、スナイプ対策の延長があります。

## 証券、暗号資産、デリバティブ

- **Securities Exchange / 証券取引所**：4 銘柄（`cs`、`tb`、`gold`、`tech`）が相関しながら 1 分ごとに動く市場です。1 日の値幅制限は ±30% です。
- **CS Token / CSトークン（`cs`）**：値動きの大きい暗号資産の銘柄で、`/証券` に統合されています。`CryptoRepo` のミリ単位の現物保有が裏付けです。
- **Daily Price Limit / 値幅制限（ストップ高・ストップ安）**：日々の基準価格から ±30% の上限で、ピンのロック（`+1` / `-1`）により片側の取引を止めます。
- **Capital Gains Tax / 譲渡益課税**：確定した現物と信用取引の利益にかかる累進課税です。
- **Cross Margin / 信用取引**：担保を共有する、レバレッジつきの買いと売りのポジションです。毎日の金利（買い `0.1%` ／ 売り `0.05%`）と、自動の損切りがあります。
- **Collateral Headroom / 担保余裕度**：口座ぜんたいの、有効証拠金 ÷ 必要証拠金です（🟢 `150%` 以上 ／ 🟡 `130〜150%` ／ 🔴 `130%` 未満）。新しく建てるには `130%` 以上が必要で、`100%` を割ると、損の大きい建玉から強制決済されます。以前の呼び名は `維持率` です。
- **Option / オプション**：Black-Scholes で値付けするヨーロピアン式のコールとプットの契約です。イベントと決算のジャンプによる分散を織り込みます。
- **Pair Warrant / ペア・ワラント**：2 つの銘柄の相対的な値動きを対象にしたオプションで、Margrabe の交換オプションの式で値付けします。
- **Earnings Release / 決算**：銘柄に対する、予定されたジャンプのショックのイベントです。ノイズのあるインサイダーのメモ（方向の精度 `70%`）が付きます。
- **Market Event / 市場イベント**：特定の銘柄に対して告知される、一時的なボラティリティの倍率の期間です。
- **Bond / 債券**：帝愛またはジャンクの、期間つきの債務商品です。CIR のリスクフリーレート（`r_f`）から値付けし、DCF による途中売却と、ジャンクの債務不履行リスクがあります。

## 帝愛銀行、融資、共済、会社

- **Teiai Bank / 帝愛銀行**：サーバーの中央銀行です。部分準備を持ち、種銭を貸し、ピンハネと手数料を集め、破綻保証と債券を引き受けます。
- **Reserve Ratio / 準備率（`θ`）**：銀行の流動的な現金と負債の比率で、取り付け騒ぎによる凍結、リスクフリーレート、共済の入口を決めます。
- **Thermostat / サーモスタット**：銀行への資金の出入りを、日々の負荷の減衰で和らげる、分割に不変な流動性ショックの吸収器です。
- **Seed Money / 種銭**：残高がゼロのプレイヤーが借りられる、帝愛の緊急融資（`3,000` ペリカ）です。借入の上限は超えられません。
- **Toichi / トイチ**：帝愛の債務の金利です。1 日 `1%` の単利で、10 日で 1 割になるのが名前の由来です（`DEBT_RATE_PER_DAY = 0.01`、リマスターでは `debtRatePerDayBps: 100`）。1 回に数えるのは最大 10 日分で、利息だけで借金が `14,999` を超えることはありません（`DEBT_INTEREST_CEILING`）。
- **Teiai Skim / ピンハネ**：帝愛が自動で取る分です（債務者の毎日の受け取りから `20%`、地下労働の収入から `3%`）。
- **Debt Withholding / 天引き**：債務者への入金や送金から、自動で `30%` を差し引き、そのまま債務の返済にあてることです。
- **Overseas Escape / 海外逃亡**：リスクの高い債務逃れの試みです（`1%` で全額帳消し、`99%` で罰金が債務に上乗せ）。
- **Teiai Trust / 帝愛信託**：帝愛銀行にあるプレイヤーの利息つき預金口座で、1 時間ごとに利回り（`r_f + premium`）が付きます。
- **CDS / 破綻保証（Credit Default Swap）**：対象のプレイヤーの債務不履行や破産に対する、保険兼賭けの契約です。状態、債務、担保余裕度から値付けします。
- **P2P Loan / 個人間融資**：プレイヤー間の融資契約です。日割りの単利、延滞ペナルティ（`max(1.5x, 2%/day)`、上限 `2x`）があり、差し押さえの順位は帝愛の次です。
- **Teiai Kyosai / 帝愛共済**：サーバーの共済ファンドです。1 サイクルにつき 100 口をオークションで発行し、ハミルトン方式で配当します。P2P の譲渡手数料は `5%` で、超過損失の徴収とガバナンスの動議があります。
- **Company / 会社**：プレイヤーが設立する生産事業（`farm`、`mine`、`factory` など）です。決定論的な毎日の市況、連続生産、外部の出資、配当があり、維持費を 3 日未払いにすると破産します。
- **Admin Tools / 管理コマンド**：サーバーのオーナーや運営者向けのコマンドで、サーバーの承認、RTP の調整、残高の調整、手動のボーナスイベント、機能の切り替えを行います。
