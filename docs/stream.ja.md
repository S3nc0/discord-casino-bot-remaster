# 配信（`/配信`）

[← README に戻る](../README.ja.md) ／ [配信の仕様](spec/stream.ja.md)

誰かの配信にスパチャを送ったり、配信者の勝ち・負けに賭けたりできます。アクティビティの**配信**画面でも、Discord チャットからでも、同じパネルと残高で遊べます。調整できる数値は `catalogs/economy.yaml` の `stream:`、配当の計算は `packages/domain/src/stream/` にあります。

## 配信パネル

- アクティビティの**配信**タイル、またはチャットで `/配信 開始` を実行し、タイトル（1〜100文字）と任意の配信リンク（`http://` または `https://`）を入れてパネルを開きます。Discord の画面共有でも、YouTube や Twitch などの外部配信でも使えます。
- アクティビティ内の配信リンクは、Discord の外部リンク確認を通って開きます。
- ボイスチャンネルに入った状態でアクティビティから開始すると、そのボイスチャンネルが場所としてパネルに表示されます。Bot がチャンネルを作成・削除することはありません。
- パネルには、スパチャの合計額と件数、いまの勝負（勝ち・負けの合計額と目安オッズ、賭けた人数、自動締切のカウントダウン）、最近のスパチャが表示されます。
- 1人が1サーバーで同時に開けるパネルは1つまでです。**配信を終える**で閉じられ、閉じ忘れても**24時間**で自動的に閉じます（未精算の勝負は無効になり、賭け金は全額返ります）。

## スパチャ

- **100ペリカ以上**の金額と任意のメッセージ（**150文字まで**）を入れて配信者に送ります。
- お金のルールは `/ペリカ 送金` と共通です。
  - **手数料 10%**（切り上げ）を送る側が上乗せで負担します。
  - **1日の上限 20,000ペリカ**は、通常の送金と合算で数えます。
  - **ゲームを3回以上遊んでいること**、および**帝愛への借金がないこと**が必要です。
  - **5,000ペリカ以上**のスパチャは送信前に確認ダイアログが出ます。
  - 配信者は自分の配信にスパチャを送れません。
- 額が大きいほど鮮やかなティア色で表示されます（青 → 水色［500〜］ → 緑［1,000〜］ → 黄［2,000〜］ → 橙［5,000〜］ → 赤紫［10,000〜］ → 赤［20,000〜］）。

## 勝敗の賭け

1. 配信者が任意の名前（60文字まで、空欄なら「次の勝負」）で勝負を開始します。
2. 視聴者が**配信者の勝ち**または**配信者の負け**に賭けます。賭け金は精算までエスクローで預かります。
3. 配信者が**賭けを締め切る**を押すか、開始から**10分**たつと自動で締め切られます。
4. 賭けが締め切られたあと、配信者が**勝ち**または**負け**を確定します（確認ダイアログあり）。**無効にする（全員返金）**は受付中・締切後のどちらでも実行できます。

未精算の勝負がある間は、次の勝負を始められません。配信を終了したときや24時間の自動終了時に未精算の勝負がある場合は、自動で無効になり全員に返金されます。

### 配当（山分け）

- 負けた側の合計から帝愛が**5%**を控除し、残りの95%を勝った側へ賭け額に比例して分配します。控除と端数は帝愛銀行の収入になります。
- 当てた人には元の賭け金が必ず戻るため、勝って損をすることはありません。
- 片方にしか賭けがなかった場合は不成立となり、全員に全額を返金します（ペリカを新しく作りません）。

例: 勝ちに A が 1,000・B が 3,000、負けに C が 2,000 賭けて配信者が勝った場合。負け側 2,000 の 5%（100）を控除した 1,900 を A と B で 1:3 に分け、A は `1,000 + 475 = 1,475`、B は `3,000 + 1,425 = 4,425` を受け取ります。

### 八百長への対策

勝敗は配信者が宣言するため、次のルールで不正を抑えています。

- 配信者本人は自分の勝負に賭けられません。
- 1人あたり1勝負で賭けられるのは**100〜10,000ペリカ**までです。同じ側への追加はできますが、反対側には切り替えられません。
- 借金がある人は賭けられません。
- **締め切る前は勝敗を確定できません**（結果が出てからの後出し賭けを防ぎます）。
- すべての精算・無効化はオーナー向けの監査ログに記録され、サーバーの持ち主は理由つきで `/運営 配信無効`（`/admin stream-void`）を実行できます。

## 機能の停止

持ち主が `/運営 機能` で `stream` を止めると、新しいパネル作成・スパチャ・賭けが一時停止されます。開いているパネルの締切・精算・無効化・配信終了はそのまま使えるため、預かった賭け金は必ず精算できます。
